# NEXA Core

**NEXA Core** is the concept of a centralized foundation for NEXA business systems.

It can provide shared functionality used across different applications.

## Potential Components

```text
NEXA Core
│
├── Authentication
├── Users
├── Roles
├── Permissions
├── Notifications
├── Activity Logs
├── API Layer
├── Settings
└── Integrations
